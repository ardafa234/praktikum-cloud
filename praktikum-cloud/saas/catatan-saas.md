# Catatan Penggunaan SaaS: Google Docs

**Layanan:** Google Docs (https://docs.google.com)

## Kegiatan yang Dilakukan

- [ ] Membuat dokumen baru berjudul "Laporan Praktikum Cloud"
- [ ] Menulis isi dokumen sesuai instruksi dosen
- [ ] Membagikan dokumen ke teman lewat tombol **Share**
- [ ] Menambahkan komentar pada bagian teks tertentu
- [ ] Mengedit bersamaan dengan teman (kolaborasi real-time)
- [ ] Melihat **Version history** (File > Version history)
- [ ] Mengunduh dokumen ke format .docx / .pdf

## Fitur yang Lebih Memudahkan Dibanding Aplikasi Lokal

| Fitur | Google Docs (SaaS) | Aplikasi lokal (mis. Word offline) |
|---|---|---|
| Instalasi | Tidak perlu, cukup browser | Harus install dan lisensi |
| Akses | Dari perangkat apa saja | Terbatas pada satu komputer |
| Penyimpanan | Otomatis tersimpan di cloud | Simpan manual, risiko berkas hilang |
| Kolaborasi | Real-time bersama banyak orang | Kirim berkas bolak-balik |
| Riwayat versi | Bawaan, bisa dikembalikan | Perlu mengelola salinan sendiri |
| Pembaruan | Otomatis oleh penyedia | Harus update manual |

## Keterbatasan yang Dirasakan

- Butuh koneksi internet (mode offline harus diaktifkan lebih dulu).
- Fitur lanjutan lebih terbatas dibanding aplikasi desktop.
- Data tersimpan di server penyedia, sehingga bergantung pada layanan mereka.
