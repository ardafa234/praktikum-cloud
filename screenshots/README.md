# Folder Screenshot

Simpan semua tangkapan layar praktikum di folder ini dengan nama berikut agar tampil otomatis di `README.md` utama:

| Nama berkas | Isi yang harus terlihat |
|---|---|
| `01-iaas-spesifikasi-vm.png` | Output OS, vCPU, RAM, dan IP dari `setup-vm.sh` |
| `02-iaas-nginx-status.png` | Hasil `systemctl status nginx` (active/running) |
| `03-iaas-nginx-browser.png` | Halaman "Welcome to nginx!" lewat Traffic/Ports (port 80) |
| `04-paas-github-repo.png` | Halaman repositori GitHub berisi folder `app/` |
| `05-paas-render-konfigurasi.png` | Form Static Site di Render (repo, branch, publish directory `app`) |
| `06-paas-render-deploy-sukses.png` | Status deploy berhasil (Live) di Render |
| `07-paas-render-url.png` | Aplikasi terbuka di URL `onrender.com` (alamat URL terlihat) |
| `08-saas-docs.png` | Dokumen Google Docs yang dibuat |
| `09-saas-share.png` | Menu Share / kolaborasi |
| `10-saas-version-history.png` | Riwayat versi dokumen |
| `11-bonus-k8s-pods.png` | (Opsional) `kubectl get pods` dan `kubectl get svc` |
| `12-bonus-k8s-hello.png` | (Opsional) Aplikasi Kubernetes di browser |

Tips: pastikan URL/alamat browser terlihat jelas, dan tidak ada data pribadi (email, token, bookmark) yang ikut terekam.
